# PixelNorte
Sitio web institucional inicial de ejemplo para una agencia de diseño y desarrollo web, que detalla información de la empresa, servicios ofrecidos y un canal de contacto.

## Tecnología
* HTML5
* CSS3 (Flexbox, Grid)

## Estructura
* `index.html`: página principal
* `servicios.html`: listado de servicios y precios
* `contacto.html`: formulario de contacto
* `style.css`: hoja de estilos 
* `logo_pixel_norte.png`: logo de la agencia
