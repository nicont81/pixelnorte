# Pixel Norte
Sitio web institucional para una agencia dedicada al diseño y desarrollo web, que detalla información de la empresa, servicios ofrecidos y un canal de contacto.

## Tecnologías
* HTML5
* CSS3 (Flexbox, Grid)

## Estructura
* `index.html`: página principal
* `servicios.html`: listado de servicios y precios estimativos
* `contacto.html`: formulario de contacto
* `style.css`: hoja de estilos compartida
* `logo_pixel_norte.png`: logo genérico de la agencia
